# Personal Health Checker 隐私保护指引草案

> 本文件是小程序体验版 / 审核前的隐私保护指引草案，不构成法律意见。正式上线前需结合主体信息、微信公众平台后台配置和法律审查完成最终版本。

## 1. 产品与主体信息

- 产品名称：Personal Health Checker
- 产品定位：个人健康记录与轻体重管理回看工具
- 运营主体：待填写
- 联系方式：待填写
- 生效日期：待填写

## 2. 我们收集的信息

为提供记录、回看、账号和数据导出能力，产品会处理以下信息：

- 账号信息：邮箱、微信小程序 `openid`、可选 `unionid`
- 个人资料：昵称、时区、体重单位、饮水单位、提醒开关
- 健康记录：睡眠时长、体重、饮水量、记录日期、补录标记
- 日常背景标签：饮食状态、活动量、精神状态、称重时段
- 目标设置：睡眠、体重、饮水目标
- 使用行为：注册、登录、页面访问、记录保存、付费意愿点击等产品事件
- 会话信息：服务端 Session、Web Cookie、微信小程序 Bearer token

当前版本不主动收集：

- 手机号
- 精确地理位置
- 通讯录
- 相册、摄像头、麦克风
- 微信运动步数
- Apple Health / Health Connect / 穿戴设备数据
- 疾病、药物、诊断、治疗记录

## 3. 信息使用目的

上述信息仅用于：

- 完成账号注册、登录和身份识别
- 保存和展示用户主动填写的记录
- 生成 Dashboard、Trends、History 等回看内容
- 计算连续记录、达标率、记录密度等基础指标
- 提供个人数据导出和账号删除能力
- 观察产品漏斗、留存和内测功能意向
- 保障系统安全和排查错误

产品不会将记录内容用于医疗诊断、疾病筛查、治疗建议或自动设备同步。

## 4. 信息存储与保护

- 密码使用哈希方式存储，不保存明文密码
- Web 登录使用 HttpOnly Cookie
- 小程序登录使用服务端签发的 Bearer token，不下发微信 `session_key`
- 用户记录存储在 PostgreSQL 数据库中
- 删除账号后，账号、资料、记录、目标、会话和微信身份映射会通过数据库关联关系清理

## 5. 用户权利

用户可以：

- 查看和修改个人资料
- 新增、修改或清空每日记录
- 导出个人资料、目标、记录、上下文标签和微信身份映射
- 删除账号及全部关联数据

当前接口：

- `GET /api/account/export`
- `DELETE /api/account`

## 6. 第三方服务

当前技术服务包括：

- Vercel：Web 与 API 部署
- Neon PostgreSQL：数据库
- Resend：可选邮件发送服务
- 微信小程序平台：小程序登录和运行环境

正式上线前需根据实际使用的服务商补齐完整第三方清单。

## 7. 未成年人保护

本产品默认面向具备独立理解和记录能力的个人用户。若涉及未成年人使用，应由监护人阅读并同意相关条款。

## 8. 变更与联系

隐私保护指引发生重大变化时，应在产品内或小程序后台更新说明。用户如需咨询、导出或删除数据，可通过待填写联系方式提交请求。
