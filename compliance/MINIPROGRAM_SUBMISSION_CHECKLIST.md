# 微信小程序体验版 / 审核前检查清单

> 本清单用于 Personal Health Checker 小程序 alpha 到体验版 / 审核前准备。平台规则以微信公众平台后台和官方文档实时结果为准。

## 1. 后台与主体

- [ ] 确认小程序 AppID
- [ ] 确认主体类型和运营主体名称
- [ ] 确认可选类目：健康管理 / 工具类低风险方向
- [ ] 确认小程序备案状态
- [ ] 配置客服入口或客服联系方式

## 2. 域名与环境

- [ ] Vercel 生产域名可访问
- [ ] HTTPS 证书正常
- [ ] 微信公众平台后台已配置 request 合法域名
- [ ] Vercel 环境变量已配置 `WECHAT_MINI_PROGRAM_APP_ID`
- [ ] Vercel 环境变量已配置 `WECHAT_MINI_PROGRAM_APP_SECRET`
- [ ] Neon 数据库连接正常

## 3. 隐私与协议材料

- [ ] 隐私保护指引完成主体、联系方式和第三方服务清单
- [ ] 用户协议完成主体、争议解决和收费规则占位
- [ ] 健康免责声明已在产品内或审核材料中可见
- [ ] 微信公众平台后台已填写用户隐私保护指引
- [ ] 如调用隐私相关接口，代码已处理授权提示

## 4. 功能自测

- [ ] 微信登录成功
- [ ] 今日记录可保存体重、睡眠、饮水和背景标签
- [ ] Dashboard 可展示今日完成度、记录率和提醒
- [ ] 体重趋势可展示最近 30 天趋势与背景回看
- [ ] 我的页可展示资料和目标
- [ ] 我的页可触发 30 天报告内测意向
- [ ] 我的页可导出个人数据
- [ ] 我的页可删除账号和全部数据
- [ ] Web Cookie 登录不受小程序 Bearer 登录影响

## 5. 审核说明

- [ ] 准备测试账号或测试路径说明
- [ ] 说明产品是个人记录工具，不提供医疗诊断
- [ ] 说明当前不接设备同步、不读取微信运动、不读取位置
- [ ] 说明报告入口仅记录内测意向，不发生支付
- [ ] 准备核心页面截图：登录、今日记录、Dashboard、趋势、我的

## 6. 商业测试门槛

建议满足以下数据后，再扩大测试范围：

- [ ] 首次完整记录率 >= 60%
- [ ] 次日回访率 >= 25%
- [ ] 7 日内平均记录天数 >= 3
- [ ] 上下文标签填写率 >= 40%
- [ ] 付费意愿点击用户占比 >= 5%
